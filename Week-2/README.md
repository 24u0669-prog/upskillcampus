#  Music playelist application 

> A modern, Java-generated music playlist with a desktop player and a
> GitHub Pages web experience.

## Overview

Java Music Player is a music-library project built with Java SE. It includes:

- A desktop music player built with Java Swing and Java Sound.
- A modern streaming-style web playlist generated by Java.
- Original demo WAV tracks and locally generated album artwork.
- Search, playlists, favorites, queue management, playback controls, and
  responsive layouts.

The browser version is published as static files, so it can be hosted on
GitHub Pages without running a Java server.

## Features

### Desktop application

- Import individual audio files or complete folders.
- Search by title, artist, album, or file path.
- Create, select, and delete playlists.
- Add and remove songs from playlists.
- Add songs to a playback queue and reorder the queue.
- Play, pause, stop, previous, and next controls.
- Seek through a track and adjust volume.
- Shuffle and repeat modes.
- Displays song title, artist, album, file name, and duration.
- Includes generated demo music for testing.

### Web playlist

- Modern streaming-service-inspired interface.
- Featured playlist hero section.
- Discover and library navigation.
- Searchable song library.
- Play and queue controls.
- Favorites and recently played filters.
- Queue removal and playback navigation.
- Album artwork for every track.
- Progress bar, elapsed time, duration, repeat, and volume controls.
- Keyboard shortcuts:
  - `Space`: play or pause.
  - `Left Arrow`: previous track.
  - `Right Arrow`: next track.
- Responsive design for desktop and mobile browsers.

## Requirements

- Java Development Kit (JDK) 17 or newer.
- A modern web browser for the web playlist.
- WAV, AIFF, or AU files for standard Java Sound playback.

## Run the desktop player

Open a terminal in the project directory and run:

```powershell
javac -d out src\MusicPlayerApp.java
java -cp out MusicPlayerApp
```

The desktop window opens automatically. Use **Import folder** and select the
`demo-music` directory to load the included tracks.

## Generate and preview the web playlist

The Java generator creates the complete `docs` website, copies audio files,
creates album artwork, and adds generated demo songs:

```powershell
javac -d out src\StaticSiteGenerator.java
java -cp out StaticSiteGenerator
```

Open the generated page locally:

```text
docs\index.html
```

Or open it directly in a browser using the file path:

```text
C:\path\to\project\docs\index.html
```

Run the generator again whenever you add or remove songs from `demo-music`.

## Publish with GitHub Pages

GitHub Pages hosts static files and does not run a Java backend. This project
uses Java to generate the static web page first, then GitHub Pages hosts the
generated output.

1. Generate the website using the command above.
2. Push the project to a GitHub repository.
3. Open the repository **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/docs` folder.
7. Click **Save**.

The published site will be available at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

The repository should contain this structure:

```text
docs/
├── index.html
├── audio/
└── artwork/
```

## Audio compatibility

Java Sound supports WAV, AIFF, and AU on a standard JDK installation. MP3 and
FLAC files may be listed in the library, but playback requires third-party
codec providers such as JavaZoom MP3SPI or JFLAC.

The included generated demo tracks are WAV files and require no additional
codec installation.

Song metadata is derived from file names using the format:

```text
Artist - Title.ext
```

Embedded ID3 or Vorbis metadata is not read by the Core Java-only version.
